# Procedural Generation and Automatic Evaluation of Game Levels

## My interpretation of the brief
The project is a system capable of procedurally generating game levels, evaluating them on a set of parameters and heuristics to calculate a set of metrics describing the quality, complexity, diversity and other similar values of the resulting map, allowing user to filter the output or find relationships between said metrics and utilized generation algorithm and its parameters.

## Why I am a good fit for this project
I am interested in furthering my knowledge in game development, and have considerable experience in procedural level generation. I find automatic evaluation to be a rather novel approach to the idea, whcih I would be interested in researching and implementing.

## Relevant experience and background
I have over seven years of open-source multiplayer game development background and creating modifications for closed-source games, as can be seen on my [main GitHub Account](https://
github.com/SmArtKar). I am one of the primary maintainers for one of the main forks of one of the oldest open-source videogames, and have vast experience with designing the architecture and optimizing performance of complex internal systems.

## Initial plan
1. Define the desired map format (top-down, platformer, 3D, etc), evaluation metrics and generation algorithms.
2. Write the specification and initial technical proposal.
3. Create the generation system(s) and an intereface for previewing generated levels.
4. Create the evaluation system and integrate it into the preview interface
5. Research correlation between utilized generator (if multiple are requested by the client) and its parameters, and evaluation metrics of the produced level(s)

## Additional information
I plan to maintain a Git repository from the start and use issues to track work.
I prefer to avoid utilizing AI/LLM tools when possible as I believe the long-term cost of system maintainability and knowledge is not worth the short-term speed tradeoff, only utilizing simplified versions as autocomplete to speed up the process of writing boilerplate code.
